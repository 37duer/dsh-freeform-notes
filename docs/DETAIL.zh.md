# 速记标签页

在 DSH（DeepSeek Harness）Web UI 的底部工作台添加一个**「速记」**页签。展开底部面板，点标签栏右侧「+」并选择「速记」（面板为空时直接点「速记」卡片），即可随手记录文字。内容保存在当前浏览器中，刷新后仍在；清除站点数据会一并清除。

## 功能

- **即开即写**：页签打开后编辑区自动获得焦点；纯文本域 + 等宽字体，无多余排版干扰。始终以纯编辑模式展示，**不做 Markdown 渲染或预览**。
- **Markdown 输入辅助**：回车自动续接当前行的 Markdown 前缀——`- ` / `* ` / `+ ` 无序列表原样续接；`1. ` 有序列表自动递增；任务列表续项自动重置为 `- [ ] `；`> ` 引用自动续接，组合前缀原样续接（`> - ` → `> - `，`> 1. ` → `> 2. `）。空列表项/空引用行回车退出对应语法（`> - ` 空项先退到 `> `），Shift+回车强制普通换行。
- **自动保存**：输入停止 400ms 后防抖写入 localStorage；页签关闭、页面隐藏、页面卸载时立即落盘。
- **多标签页同步**：同一浏览器其他标签页写入的速记经 `storage` 事件实时同步；本页有尚未落盘的输入时以本页为准，避免双方在防抖窗口内互相覆盖。
- **字素级字数统计**：以用户感知字符计数（`Intl.Segmenter`，grapheme 粒度），emoji、组合字符计 1；不支持 Segmenter 时退化为码点计数。
- **存储降级**：localStorage 不可用或已满时，状态栏转为错误提示（「内容仅保留在当前页面」），文本仍可在当前页面继续编辑，仅不持久化。
- **可访问性**：编辑区带 `aria-label`；保存失败经 `role="alert"` 向读屏播报；状态区保留 `title` 提示；键盘焦点有可见轮廓。
- **触屏适配**：粗指针设备上编辑区字号自动升至 16px，避免 iOS 聚焦缩放。
- **主题融合**：配色与字体全部取自宿主设计令牌（`--dsw-alias-*`、`--ds-font-family-code`），明暗主题自动跟随。

## 数据如何保存

- 速记以 `{"text": "…"}` 存入 `localStorage`，键为 `dsh.freeform-notes.v1`。
- 全部内容仅存于本浏览器：插件不发起任何网络请求，不上传文本。
- 清除站点数据（或单独删除上述键）即永久删除速记，不可恢复。

## 运行要求

- DSH Web UI，且 `dsh-better-sidebar` 模块与 locale 服务可用（两者均经 client 注入）。
- 支持 `localStorage` 的浏览器（主流浏览器均可）；存在 `Intl.Segmenter` 时优先使用。

## 已知限制

- 单条速记：仅一个文本域，暂无多笔记、Markdown 渲染/预览、检索或导出能力（编辑侧提供列表/引用回车续行等 Markdown 输入辅助）。
- 仅存本浏览器，不做云同步与跨设备。
- 页签内 UI 文案仅内置简体中文与 English，其余语言回退英文（注册表元数据为 8 语言）。
- DSH 处于 developer preview：本插件按 client 模块契约（`window.__ModuleLoader__.load` + `apply(ctx)`）与 `betterSidebar.registerTab` 契约编写，契约变更时需同步调整。
